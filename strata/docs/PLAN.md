# Strata 기획서

연구 주제(프로젝트)별로 국내외 논문을 넓게 찾고, 고른 논문의 초록을 요약해 쌓아 두는 연구실 공유형 앱입니다.
PDF는 저장하지 않고 서지 정보, 원문 초록, 요약, 메모만 보관합니다.

- UI 시안: [`ui-mockup.html`](./ui-mockup.html) (브라우저로 열면 클릭해 볼 수 있음, 예시 데이터)
- 대상 분야(기본값, 설정에서 편집 가능): 교육학 · 교육공학 · 학습과학 · 인지심리 · 국어교육 · 교육평가 · 디지털 평가문항

## 1. 핵심 결정

| 항목 | 결정 |
|---|---|
| 사용자 | 연구실 동료 여러 명. 로그인 필요, 프로젝트 공유 |
| 구성 | Next.js + Supabase(로그인·DB) · Vercel 배포 |
| 로그인 | Google 계정 + 이메일 링크 |
| AI 요금 | 각자 개인 Anthropic API 키 (암호화 저장, 끝 4자리만 표시) |
| 요약 모델 | Claude Sonnet 5.5 · 공백 지도 일괄 분류는 Claude Haiku 4.5 (설정에서 변경 가능) |
| 화면 테마 | 주간 / 야간 / 시스템 따라가기 (설정) |

## 2. 화면 구조

- **사이드바** (머리글을 눌러 여닫기, 상태 기억)
  - 내 프로젝트 / 공유받은 프로젝트
  - 서재: 전체 서재 · 읽을 것 · 최근 2주 보관 · 별표 · 새 논문 알림
  - 분야: 분야별 논문 수, 누르면 그 분야만
  - 내 계정: 이번 달 AI 사용 금액 한 줄
- **프로젝트 화면**: 이름 · 연구 질문 · 멤버/공유 → 새 논문 알림 줄 → **큰 검색창** → 탭
  - **검색 결과**: 확장 검색어 칩, 범위(전체/국내/해외), 출처, 정렬(관련도·영향력·피인용·최신), 상위 10%·리뷰만 필터, 최근 검색, 이 검색 저장, 결과 목록 + 요약 트레이
  - **비교표**: 소주제·분야·연도로 묶기, 열 = 논문/분야/영향력/대상/설계/주요 결과/시사점/상태, 표 복사·참고문헌(APA) 복사, 핵심 문헌 후보
  - **대시보드**: 숫자 카드 4개, 연구 공백 지도, 연구 동향, 소주제별 편수(보강 필요 표시), 출판 연도, 연구 유형, 영향력 분포, 읽기 상태, 주별 보관, 최근 활동(공유 프로젝트)
  - **관계도**: 관계망(Obsidian식) / 연도 계보(가로 = 연도, 세로 = 소주제)
- **전체 서재**: 모든 프로젝트의 논문, 분야 필터, 프로젝트에 추가, DOI·URL로 직접 추가
- **설정**: 계정 · 이번 달 AI 사용량(월 한도) · 화면 · 요약 엔진(API 키) · 내 연구 위치 · 분야 관리 · 데이터 내보내기

## 3. 기능 상세

### 검색
- 출처
  - 해외: OpenAlex · Semantic Scholar · ERIC · (선택) PubMed
  - 국내: Crossref · OpenAlex(DOI가 등록된 국내 학술지) + KCI · RISS · DBpia · Google 학술검색으로 가는 링크 + DOI 붙여넣기 / 직접 입력
  - KCI Open API는 담당자 승인과 고정 서버 IP 등록이 필요해 1단계에서는 쓰지 않는다. 국내 논문이 너무 안 잡히면 고정 IP 중계 서버를 두고 붙인다
  - 학위논문: 국회도서관 Open API (3단계, 키 신청 필요)
- Claude가 프로젝트 연구 질문과 분야를 보고 **한국어·영어 검색어**로 넓힘 (칩으로 수정 가능)
- 검색어 × 출처를 병렬 수집 → DOI·제목 기준 중복 제거 → 순위 결합
- 인용 추적: 이 논문을 인용한 논문 / 참고문헌 / 비슷한 논문
- 저장
  - 검색 기록: 검색어·필터·결과 목록을 프로젝트에 30일 보관, 다시 검색 없이 열기
  - 저장한 검색: 기간 제한 없음, 매주 새 논문 알림
  - 논문 보관: 요약 후 소주제에 보관

### 품질·영향력 지표 (AI 사용 없음)
- 분야·연도 보정 피인용 백분위(상위 1% / 10%) — OpenAlex
- 핵심 인용(본문에서 실질적으로 쓰인 인용) — Semantic Scholar
- 학술지 수준: SCImago 사분위(연 1회 목록 갱신) / KCI 등재·등재후보
- 저자 최고 h-index — OpenAlex
- 연구 유형(메타분석·리뷰·실험 등) — 요약 호출에서 함께 판정
- 출판 2년 이내 논문은 "최근 논문 · 판단 이름"으로 따로 표시, 책 장·보고서·학위논문은 종류 표시

### 요약
- **사용자가 고른 논문만** 요약 (자동 요약 없음)
- 형식: 한 줄 요약 / 대상 / 설계 / 결과 / 시사점 / 키워드. 초록에 없는 내용은 "초록에 언급 없음"
- 같은 호출에서 분야 · 연구 유형 · 대상 학교급 · 연구 방법 · 새 분야 제안까지 함께 받음
- 같은 논문(DOI 기준)의 요약은 다른 프로젝트·다른 멤버가 **재사용** (추가 비용 없음)
- 초록이 없으면 다른 출처에서 다시 찾고, 그래도 없으면 "초록 없음"으로 보관 가능

### 분야
- 고정 목록이 아니라 편집 가능한 데이터 (이름·설명·색·순서·숨기기)
- Claude는 분류할 때 현재 목록과 설명을 참고, 맞는 분야가 없으면 새 분야 제안
- "기존 논문 다시 분류": 자동으로 붙은 분야만 다시 판단, 직접 지정한 분야는 유지
- 분야와 별개로 자유 태그

### 공유
- 권한: 소유자 / 편집 가능(검색·요약·보관·정리) / 보기만(열람·메모)
- 비교표에 보관한 사람 표시, 대시보드에 최근 활동
- 메모: 공동 메모 / 나만 보기
- 요약은 실행한 사람의 키로 한 번만 만들어지고 멤버 모두가 봄

### 시각화
| 시각화 | 데이터 | AI |
|---|---|---|
| 관계도 · 연도 계보 | OpenAlex 참고문헌 목록 | 없음 |
| 핵심 문헌 후보 | 보관 논문들이 함께 인용하는 미보관 논문 | 없음 |
| 연구 동향 | OpenAlex 연도별 집계 | 없음 |
| 대시보드 차트 | 저장된 데이터 | 없음 |
| 연구 공백 지도 (국가·출판 시기 축) | 저자 소속 국가, 출판 연도 | 없음 |
| 연구 공백 지도 (학교급·방법·직접 정의 축) | 검색 상위 300편 분류 | 누를 때만, 결과 저장 |

- 연구 공백 지도: 소주제 × 축(대상 학교급 / 연구 방법 / 국가·지역 / 출판 시기 / 직접 정의), 빈칸 = 연구 공백, "내 연구 위치" 표시, 칸을 누르면 그 조합으로 검색, **지도 저장(날짜별 저장본)** · 표로 복사

## 4. AI 사용과 비용

AI를 쓰는 곳은 검색어 확장, 고른 논문 요약, 공백 지도 분류(누를 때만) 세 군데뿐입니다.

| 작업 | 예상 비용 |
|---|---|
| 초록 요약 1편 (Sonnet 5.5) | 약 $0.01 |
| 검색어 확장 1회 | 약 $0.004 |
| 공백 지도 분류 1회 (300편, Haiku 4.5 + Batch API) | 약 $0.07–0.15 |
| 활발한 사용자 한 달 (검색 80 · 요약 60 · 지도 4) | 약 $1.5 |

- 화면 곳곳에 비용을 표시하지 않고, 사이드바 "내 계정"과 설정에 **이번 달 사용 금액**만 보여줌
- 월 한도(기본 $5)에 닿으면 요약을 멈추고 알림

## 5. 구현 단계

1. **1단계 (구현됨)**: 로그인(가입 이메일 제한), 프로젝트·공유, 검색(OpenAlex · Semantic Scholar · ERIC · Crossref), 국내 사이트 링크, DOI·직접 추가, 인용 추적, 검색 기록·저장, 요약·재사용·보관, 영향력 지표, 비교표, 서재, 분야 관리, 이번 달 사용량
2. **2단계**: 대시보드, 관계도, 연구 동향, 핵심 문헌 후보, 저장한 검색 주간 알림, 영향력 지표 전체
   - 진행: 대시보드 ✓, 핵심 문헌 후보 ✓ (인용 관계를 불러올 때 빠진 영향력 지표도 채움), 관계도 ✓
3. **3단계**: 연구 공백 지도(저장 포함), 학위논문(국회도서관), 내보내기(BibTeX · RIS · Markdown · 백업)
